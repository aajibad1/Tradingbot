# 12 Customer and Partner Onboarding

## Purpose
Defines the user, developer, and partner onboarding package needed to activate customers successfully.

## User onboarding
- signup flow
- email verification
- profile setup
- KYC/KYB start
- plan selection
- first dashboard walkthrough
- first value milestone

## Developer onboarding
- create account
- generate sandbox key
- test first API call
- configure webhooks
- inspect logs
- pass integration checklist
- request production access

## Partner onboarding assets
- welcome email sequence
- quickstart guides
- API docs
- Postman collection
- webhook examples
- troubleshooting guide
- production readiness checklist
- support escalation guide

## Activation milestones
- account created
- verification completed
- sandbox first success
- production approval granted
- first live successful event
- first week retained
