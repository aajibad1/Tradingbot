# 02 Product Requirements

## Purpose
Defines end-to-end product requirements from onboarding through operation and offboarding.

## User types
- trader
- team operator
- partner developer
- admin
- compliance reviewer
- support user

## Functional areas
- auth and tenanting
- onboarding and verification
- KYC/KYB and compliance
- billing and subscriptions
- trading intelligence
- Africa API orchestration
- dashboards and analytics
- support and admin controls
- offboarding and account lifecycle

## Core requirement principle
The external experience must feel simple, while the internal system remains auditable, controlled, and extensible.
