# 04 Dashboard Blueprint

## Purpose
Defines the vision for the three role-based consoles.

## Consoles
- Intelligence Console: trader/user decision-support surface with agent debates, opportunity feed, risk strip, capital, route quality, and evidence log.
- Orchestration Console: partner/developer control plane with rails, corridors, logs, webhooks, API keys, settlement monitoring, and route analytics.
- Control Console: admin/ops/compliance surface with queues, audit trail, connector health, policy timeline, and oversight tools.

## Shared design principles
- calm institutional visual language
- one design system across all consoles
- role-specific density
- explanation before action
- evidence-linked intelligence
